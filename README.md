# 出席カード読み取り (Streamlit)

机に並べたカードの写真から、1 枚ずつ正しい向きで切り抜き、学籍番号を抽出して
「学籍番号 ＋ 切り抜き画像」の一覧にするアプリ。

## 起動

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

## 処理の流れ

1. `cards.detect_cards` : 机の色（最頻色）との色味の差でカード領域を抽出し、矩形を検出
2. `cards.warp_card` / `orient_card` : 射影変換で横長に切り出し、表罫線の上下余白から 180° 反転を補正
3. `cards.id_cells` : 学籍番号行をマス（A＋数字7桁）に分割し、罫線を除去
4. `ocr.orient_and_read` : 向きを中身（数字らしさ）でも確かめてから読み取る
   - **数字CNN**（既定）: マス単位で 1 桁ずつ分類。桁ごとの確信度を出し、0.85 未満の桁があるカードを「要確認」にする
   - 学籍番号のルール（`idrule.py`）で絞り込む: 先頭は A/H を形で判定、入学年度 2 桁は 20〜26 の中から選ぶ
   - **Indra OCR**: マスを連結して読ませる。手書きの 1 桁ずつは取りこぼしが多い
5. UI で学籍番号を手修正 → CSV / 切り抜き画像 ZIP をダウンロード

## CSV 並べ替えページ

サイドバーの「CSV並べ替え」から、複数の CSV を結合して学籍番号順に並べ替える（`sorting.py`）。

- 並び順: 先頭の英字（A → H）ごとにまとめ → 入学年度 2 桁（20〜26）→ 残りの桁を昇順
- 学籍番号の列は自動判定（列名、無ければ値の形式から推定）。違えば画面で変更できる
- 全角・小文字・空白は正規化。学籍番号のルールに合わないものは末尾にまとめる
- 重複の検出と、1 件にまとめるオプション。UTF-8 / Shift_JIS の CSV に対応

## 既知の制約

- 机と同系色（白いカードを白い机に置く等）は検出しにくい。「カード検出の調整」で感度を上げる
- カード同士が接触・重なっていると 1 枚として検出できない（少し離して撮影する）
- 学籍番号は「英字（A/H）＋数字 7 桁」のマス目レイアウトを前提にしている
- 1 枚の写真に 40 枚以上写すと 1 桁が 15px 程度になり誤読が増える（実写 41 枚で桁正解 89%・完全一致 49%）。
  10〜15 枚ずつ撮影すると解像度が上がり精度が上がる
